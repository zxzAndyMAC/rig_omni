# 03: 亮度主题表情运动预览与重启

**What to build:** 同一条蓝牙 JSON 能调亮度、主题、表情、转头、平移、旋转，能让摄像头拍到机器人屏幕（图不外传），危险区能重启且 Wi-Fi 还在。

**Blocked by:** 01 联网后能被扫到并读出状态

**Status:** ready-for-agent

- [ ] 亮度、主题、表情、转头、平移、旋转各至少一条成功请求有可见效果
- [ ] 预览成功后机器人屏幕出现刚拍的画面，应答不含图片字节
- [ ] 重启后设备仍用家里 Wi-Fi 连上，广播名不变
- [ ] 未知 method 返回错误，不复位
- [ ] 烧录前停住，等人确认
