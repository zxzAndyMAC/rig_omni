# 01 — 先当用户玩通一遍

Status: resolved  
Step: 1 / 6（见 `../spec.md` 学习路线）  
Completed: 2026-09-05（用户确认：官方云玩通）

## 目标

确认：**硬件正常 + 官方云能聊能控**。后面改固件、换服务器时，才有「已知正常」的对照基准。

## 检查清单

### A. 上电与平衡

- [ ] 轮组转动顺畅、无异物
- [ ] 头部舵机可水平轻拨、无卡死
- [ ] Type-C 尽量先充满电
- [ ] **手扶竖直**放置 → 开电源 → 扶稳约 2–3 秒等 IMU
- [ ] 感到轮部轻微「对抗」后再松手，能自平衡站立

### B. 配网

- [ ] 手机开蓝牙；扫屏上二维码进「小陆同学」小程序（或桌面站）
- [ ] 添加设备，选 `RIG-Hover-XXXX`
- [ ] 填 **2.4GHz** WiFi（5G 通常不行）
- [ ] 配网成功；**重启失衡时扶住设备**

备选：桌面站 https://agent.xgorobot.com/

### C. 交互验收

- [ ] 唤醒词「小陆同学」，有反应（表情/头动/应答）
- [ ] 摸头：单击 / 双击有动作或音效
- [ ] 语音：「今天天气」或笑话等，能听懂并说话
- [ ] 试指令：头部左转/右转、身体转向、前进/后退
- [ ]（若支持）拍照 / 「看看这是什么」

### D. 异常时先查

| 现象 | 先查什么 |
|------|----------|
| 站不住、直接倒 | 启动是否竖直；电量；桌面是否不平 |
| 转向飘 | 轮磨损/安装是否对称；窄轮距有无异物 |
| 配不上网 | 是否 2.4G；重启后是否扶住 |
| 能站但不能聊 | WiFi、小程序设备是否在线、官方云是否正常 |

## 完成标准

能稳定站立 + 配上网 + 唤醒对话 + 至少一个运动指令成功 → **本步完成**，进入第 2 步「本地编译官方 Hover 固件」。

## 备注

本步**不改代码、不换服务器**。发现问题先记现象，再对照官方 FAQ / 语雀。
